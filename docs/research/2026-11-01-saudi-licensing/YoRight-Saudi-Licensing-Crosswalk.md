# مطابقة مسميات صناعة السفر بالتصنيف السعودي
تاريخ التحقق: 1 نوفمبر 2026. نطاق العمل: مقارنة الأنشطة، دون افتراض فئة ترخيص YoRight أو تغييرها.

## الإطار الرسمي

تنص المادة الرابعة من اللائحة المنشورة في 11 سبتمبر 2026 على فئتين: «وكالة سفر وسياحة» و«خدمات سفر وسياحة عام». يشمل نطاق الأولى بيع حجوزات الإقامة والتذاكر والبرامج الجاهزة والاستشارات وبعض الخدمات المساندة؛ وتضيف الثانية إعداد البرامج، وتنفيذها محليًا، والكونسيرج، وترتيب النقل والحجوزات الخاصة وخدمات أخرى. اختيار خدمة واحدة أو أكثر لا يثبت أن ترخيص المنشأة يتضمنها جميعًا. [اللائحة، المادة 4](https://www.uqn.gov.sa/decisions-and-regulations/4001822).

التصنيف التجاري العالمي يصف دور الشركة في سلسلة التوزيع؛ الفئة السعودية ترتبط بالخدمات التي تمارسها المنشأة. المطابقة أدناه تفسير وظيفي للنصوص، وليست شهادة أهلية للشركات الأجنبية أو حكمًا على ترخيص المالك.

## المطابقة الوظيفية

| المسمى/العمل | نتيجة المطابقة |
|---|---|
| شراء فنادق عبر RateHawk أو TBO أو Stuba أو Bedsonline وإعادة بيعها للمسافر | خدمة بيع حجوزات الإقامة؛ واردة في نطاق الوكالة، وتشملها العامة أيضًا. طريقة Net + Markup ليست فئة ترخيص قائمة بذاتها. |
| Bedbank / Wholesaler | اسم تجاري للمورد. استخدام بوابته لا يحوّل وكالة المالك إلى مورد جملة. تأسيس نشاط يوزع على وكالات أخرى يحتاج تحديد نطاقه التجاري والتقني قبل تقرير متطلباته. |
| Tour Operator | بيع برنامج أعدّه مورد: نطاق الوكالة. تصميم البرنامج نفسه أو تنفيذه داخل المملكة: من إضافات العامة. |
| DMC | لا مقابل اسميًا مستقلًا في المادة 4. أعمال إعداد الرحلات والاستقبال والنقل والتنفيذ المحلي تتطابق وظيفيًا مع خدمات العامة؛ يلزم تحديد الخدمات الفعلية. |
| Concierge | تلبية طلبات السائح الشخصية والتنسيق لها: خدمة مذكورة ضمن العامة. مجرد تسمية حجز الفندق كونسيرج لا يبدّل طبيعة العمل. |
| Direct Contracting | التعاقد مباشرة مع الفندق طريقة توريد؛ إعادة بيع الغرفة تظل بيع إقامة. تشغيل الفندق أو مركبات النقل بنفسك مسألة مختلفة عن ترتيب الخدمة. |
| OTA | قناة بيع إلكترونية، وليست فئة ثالثة في المادة 4. تتحدد الفئة بحسب الخدمات؛ العمل الإلكتروني له متطلباته أيضًا. |
| GDS مثل Amadeus / Sabre / Travelport | نظام وصول للمحتوى. بيع التذاكر خدمة مرخصة، وليست امتلاك اشتراك GDS وحده. |
| API Aggregator / Hub مثل Travelgate وJuniper Hub | وصف للتقنية. لا تتضمن المادة 4 رخصة باسم المنصة؛ اختلاف كون المنشأة تقنية بحتة أو بائع سفر يغيّر المسألة. لا يثبت ذلك إعفاءها من سائر التنظيمات. |
| Booking Engine | برنامج حجز، لا يحدد وحده الفئة أو حقوق التوزيع. |
| Host Agency / Consortium / Preferred Programme | علاقة تعاقد أو عضوية، لا تستبدل نطاق الترخيص السعودي. يلزم تقييم العقد والخدمات؛ لا تنشئ العضوية وحدها حق تقديم كل خدمة. |
| Metasearch / Affiliate | الإحالة أو الإعلان لا يساويان تلقائيًا إتمام حجز وتحصيل ثمنه؛ يلزم تحديد دور المنصة قبل الحكم بمتطلباتها. |
| Direct Supplier | مقدم الخدمة نفسه يخضع لتنظيم تشغيل خدمته. ترتيب الإقامة أو النقل لا يعني ترخيص تشغيل الفندق أو النقل. |

المقابلات التشغيلية مستندة إلى المادة 4 وشرح الوزارة لخدمات البيع والترتيب. [شرح الوزارة](https://mt.gov.sa/ar/faq/faq-category-2).

الوزارة تشرح الكونسيرج بوصفه تنسيقًا لاحتياجات فردية مع مزوديها، ولا تعتبره تصريحًا لتنفيذ أعمال المطاعم أو النقل بنفسك. وتشرح بيع الإقامة بما يشمل عرض الوحدات والحجز والتعديل والإلغاء والمدفوعات. [الأسئلة الشائعة الرسمية](https://mt.gov.sa/ar/faq/faq-category-2).

## ما يخص YoRight

- نموذج شراء غرفة وإعادة بيعها يطابق وظيفة حجز الإقامة.
- إضافة إعداد رحلات أو نقل أو كونسيرج توسع الخدمة إلى عناصر من العامة.
- الفئة المدونة في ترخيص المالك وخدماته وصلاحيته لم تُقرأ في هذه المراجعة؛ لا أقرر ضرورة إصدار رخصة جديدة.
- واتساب وسيلة تواصل، ولا يكفي وحده لتقرير نطاق الترخيص أو استيفاء شروط تقديم الخدمات إلكترونيًا.
- نصت المادة 21/8 على اشتراط موافقة الوزارة قبل تنفيذ بيع تذاكر بأرقام IATA لجهات خارج المملكة؛ لذلك لا يجوز تعميم صلاحية نموذج الوكالة المضيفة الأجنبية على نشاط الطيران السعودي. هذا قيد للطيران ولا ينسحب تلقائيًا على شراء الفنادق.

## الأنشطة والتراخيص القائمة

صفحة الوزارة تربط الوكالة بالرمز 791101، والعامة بالرمزين 791101 و791223. رمز السجل ليس بديلًا عن الترخيص. [متطلبات الخدمة](https://mt.gov.sa/ar/eservices/request-to-issue-new-travel-and-tourism-license).

آلية الانتقال تبقي الفئتين الرئيسيتين، وتنقل فئة حجز وحدات الضيافة القديمة إلى الوكالة، وتنظيم الرحلات القديمة إلى العامة، مع أحكام لدمج التراخيص. المهلة القصوى 180 يومًا من النفاذ أو انتهاء الترخيص، أيهما أسبق. لم أحسب موعدًا خاصًا بالمالك لعدم معرفة انتهاء ترخيصه. [الآلية المنشورة](https://www.uqn.gov.sa/decisions-and-regulations/4001821).

للتوثيق فقط: قرار 25 سبتمبر 2026 حدّد ضمان العامة بـ50,000 ريال سعودي، و800,000 ريال سعودي إذا شملت الخدمة ترتيب تأشيرات للقادمين للمملكة. هذه ضمانات وليست رسوم اشتراك أو مطالبة مالية على المالك في هذا التقرير. [قرار الضمان](https://www.uqn.gov.sa/decisions-and-regulations/4001942).

## الحد الفاصل والنتيجة

اسم المورد الأجنبي وعقده وسعره شيء؛ نطاق الخدمات المسموح للوكالة السعودية بممارستها شيء آخر. نتيجة مراجعة الأنظمة مكتملة للمقارنة الوظيفية أعلاه؛ النتيجة الخاصة بترخيص YoRight تبقى غير محسومة حتى الاطلاع على فئته والخدمات المسجلة فيه. بعض النماذج، مثل توزيع الجملة أو المقارنة التقنية البحتة، تحتاج وصف تشغيل محدد أو إفادة الوزارة قبل الجزم؛ لم تُرسل مراسلة للوزارة أو يُعدّل ترخيص.
