# Project Overview

## Purpose

yoright is an Arabic-first online travel agency product. The repository should make its approved web application, integration contracts, and operating knowledge recoverable without relying on one AI or hosted-development platform.

## In scope

- Application code and sanitized configuration documentation.
- Generic booking-supplier integration contracts and test guidance.
- Privacy-preserving architecture and operational procedures.
- Project state, decisions, handoffs, and migration evidence.

## Out of scope

- Credentials, default passwords, or production tokens.
- Traveler profiles, bookings, passports, residency identifiers, and payment data.
- Raw supplier responses containing personal or commercial data.
- Raw AI conversations and unreconciled platform-local memory.

## Current migration concern

The reviewed sources identify multiple implementation copies or architectures, insecure default administrative access, and privacy work still to complete. The immediate goal is safe reconciliation and validation, not a live deployment change.
