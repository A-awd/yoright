# Migration Source Index

This index records source classes used for the sanitized foundation without copying source contents.

## Approved sources

- Final One Brain registry, repository plan, unification plan, naming map, and sensitive-data exclusions.
- Existing yoright GitHub code, documentation, branches, and Git history.
- Sanitized architecture and integration facts reconciled in the migration inventories.

## Excluded sources

- Raw AI conversations and hosted-platform memory.
- Credentials, traveler and booking records, identity documents, payment data, and unsanitized API responses.
- Unverified clones not reconciled with GitHub.

## Reconciliation rule

The latest approved GitHub state is authoritative. Conflicting copies remain evidence until a numbered decision establishes a replacement.
