# البحث عن تذكرة

الهدف: بحث فعلي قابل للمراجعة، بإجمالي المنصة النهائي وحدود تغطية ظاهرة. وجود منصة في السجل لا يعني فحص مخزونها. اقرأ [خطوات التنفيذ وعقد السجل](references/workflow.md) قبل بدء البحث، و[السجل الأساسي](references/platforms.json) لاختيار النطاق.

## التشغيل

1. اقرأ التوجيه الحالي من `A-awd/ai-operating-system` على `main` ثم تعليمات المصدر المالك. المصدر الحالي لهذه المهارة `A-awd/yoright`، الفرع المعتمد `migration/one-brain-foundation`؛ تحقق منه مجددًا. Easy Life متوقف؛ لا تشغّل موصله أو بديلًا عنه.
2. اكتشف أدوات الموصلات والمتصفحات واختبر الوصول الفعلي. سمِّ المتصفح المحلي أو السحابي وحدد ثبوت الجلسات. استخدم موصلًا كافيًا للعملية، ثم المتصفح للبحث الداخلي والاختيارات والرسوم. غياب موصل لا يعني استحالة البحث. عند الحظر وثّق نصه وسطح الأداة؛ لا تدّع أنه حظر لدى المستخدم أيضًا.
3. ثبّت المناسبة من المنظم أو النادي أو الفنان الرسمي: الأسماء البديلة، التاريخ والسنة والتوقيت المحلي، المدينة والدولة والملعب. استخرج العدد والتجاور والجمهور/الفريق الضيف والأهلية والعمر والعضوية والميزانية والفئة. اسأل سؤالًا محددًا فقط إذا بقي غموض يغيّر المناسبة. لا توصِ بعرض لمناسبة لم تثبت رسميًا.
4. أعلن المنصات المستهدفة من السجل والمصادر الرسمية والمحلية وما يكشفه البحث. افصل غير المناسب مع السبب، وأبقِ المرشحين غير المثبتين ظاهرين. أنشئ JSON للسجل قبل الفحص؛ لكل هدف صف واحد حتى عند التعذر.
5. لكل منصة مناسبة: ابحث داخلها؛ طابق المناسبة؛ اضبط العدد؛ رتّب بالأقل؛ افتح أرخص عرض مستوفٍ للشروط؛ افحص المقعد والرؤية والتجاور والجمهور والأهلية والتسليم؛ انتقل إلى شاشة إجمالي الرسوم دون إنشاء التزام. إذا تعذر الأرخص وسعيت إلى عرض آخر فسمِّه عرضًا مؤكدًا فقط، وسجّل عائق الأرخص.
6. النهائي يشمل رسوم الخدمة والحجز والتسليم والضريبة ورسوم الدفع/العملة الإلزامية. افصل الإضافات الاختيارية. إذا تعذرت معرفة رسوم إلزامية أو بقي تضارب `incl. fees` مع الفلتر، فالحالة `offer_fees_unconfirmed`. لا تستنتج فرق الرسوم بطرح صورتين غير متطابقتين.
7. احفظ الوقت والرابط العام والملاحظة المباشرة ومستوى الدليل والحالة لكل هدف. `event_not_found` يتطلب بحثًا داخليًا محددًا؛ لا يعني نفاد التذاكر. نتيجة Google اكتشاف فقط. اذكر وسيلة التسليم وموعده، ومصدر التحويل وتوقيته؛ ميّز ريالًا تحصله المنصة عن ريال محسوب للمقارنة، ولا تشمل رسوم البنك المجهولة.
8. شغّل المدقق والتقرير حسب README. يبدأ التسليم بأرخص إجمالي مؤكد ضمن العروض المفحوصة، أو بعدم وجود إجمالي مؤكد؛ يليه جدول جميع المنصات ثم العوائق والخطوة المحددة. أظهر عدد المستهدفة ومكتملة الفحص والإجماليات المؤكدة وغير المحسومة. لا تستخدم «الأرخص عالميًا» مع أي تغطية ناقصة.

## حدود التفويض

مسموح: فتح الصفحات والعروض والتنقل إلى خطوات السعر دون شراء، وإغلاق نافذة شرح/بدء عداد تلقائي للأسعار إذا لم يتضمن قبول شروط أو إرسال طلب أو التزام. ظهور قفل سعر أو عداد تلقائي بمجرد فتح الدفع ليس بحد ذاته طلب شراء ملزمًا. توقف عند طلب بيانات شخصية أو تسجيل دخول أو تحقق بشري واشرح ما ينقص؛ استخدم آلية الأداة لتسليم التحكم إن توفرت. لا تُنشئ حسابًا أو تقبل شروطًا تعاقدية أو تنفّذ حجزًا ملزمًا/طلبًا أو تدفع أو تشترك أو تتواصل باسم المستخدم أو تنشر في الإنتاج دون تفويض مستقل. لا تحفظ رموز الجلسات أو روابط دفع أو بيانات عملاء في المستودع.

المدقق يثبت اتساق السجل؛ لا يثبت أنك زرت المنصة أو صحة أدلتها. أرفق الأدلة المنقحة واذكر عدم اليقين صراحة.
