# تشغيل «البحث عن تذكرة» في Codex

المصدر المعتمد هو هذا المجلد في `A-awd/yoright` على الفرع المعتمد `migration/one-brain-foundation`. هذه مهارة للبحث اليدوي المنظم مع سجل ومدقق محلي، وليست تكاملًا مع مخزون التذاكر أو برنامجًا يشتري/يحجز آليًا.

يمكن تشغيلها فورًا داخل نسخة المشروع بقول:

> استخدم مهارة «البحث عن تذكرة» في `skills/search-tickets/SKILL.md` للبحث عن تذكرة واحدة لسبورتينغ وبرشلونة في لشبونة، بالسعر النهائي شامل الرسوم، واعرض سجل التغطية.

## التثبيت في بيئة Codex المختارة

من نسخة موثوقة محدثة للمستودع، اقرأ `SKILL.md` أولًا ثم اربط المجلد بدليل مهارات المستخدم في **الجهاز الذي يعمل عليه Codex فعلًا**:

```bash
mkdir -p ~/.agents/skills
ln -s /absolute/path/to/yoright/skills/search-tickets ~/.agents/skills/search-tickets
```

لا تستبدل مهارة موجودة ولا تستخدم مسار المثال حرفيًا؛ افحصه وحدد مسار نسختك. بديل الرابط: نسخ المجلد كاملًا مع المراجع والبرامج. افتح جلسة Codex جديدة كي يُعاد اكتشاف المهارة، ثم استدعها بـ `$search-tickets` أو بطلب «استخدم البحث عن تذكرة». إن لم تُكتشف تلقائيًا، مرّر مسار `SKILL.md` صراحة. تثبيت سحابي لا يثبت تثبيتًا على جهاز المستخدم، وتثبيت المهارة لا يمنحها حسابات المتصفح أو حسابات الموردين.

## إنشاء سجل وتدقيقه

كل البرامج تعمل بـ Python 3 والمكتبة القياسية، دون مفاتيح أو اتصالات خارجية. من جذر المستودع:

```bash
python3 skills/search-tickets/scripts/init_run.py /tmp/ticket-run.json \
  --quantity 1 \
  --platform stubhub-us=https://www.stubhub.com/ \
  --platform sporting-official=https://www.sporting.pt/en/tickets
```

هذا ينشئ سجلًا **غير مفحوص** ولا يفتح أي موقع. املأ المناسبة والملاحظات الفعلية بعد البحث؛ لا تحوّل القيم الافتراضية إلى دليل. ملف موجود لا يُستبدل. الخيارات الكاملة: `python3 skills/search-tickets/scripts/init_run.py --help`.

```bash
python3 skills/search-tickets/scripts/validate_run.py /tmp/ticket-run.json \
  --report /tmp/ticket-report.md
python3 -m unittest discover -s skills/search-tickets/tests -v
```

المدقق يرفض غياب هدف أو ادعاء إجمالي نهائي دون حقول التحقق، ويحسب الأعداد ويُخرج تقريرًا عربيًا إذا نجح. لا يتحقق من صدق البيانات على الموقع؛ الأدلة المنقحة والمراجعة البشرية لازمتان. لا تُدخل معلومات شخصية أو روابط دفع/جلسات؛ فحص URL احترازي وليس ماسح أسرار شاملًا.

احفظ السجلات المنقحة ذات الصلة بالمشروع في `docs/research/tickets/runs/`، وحدّث الحالة والتسليم في المصدر المالك بعد تقدم مهم. لا تُودِع صورًا أو استجابات مورد خام قبل مراجعتها للخصوصية.
