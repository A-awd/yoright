# 0001 — Adopt the One Brain repository foundation

- Status: Accepted
- Scope: Repository operating model

## Decision

yoright is the single canonical project name and repository. GitHub is the permanent source of truth. Every meaningful session begins from the latest approved GitHub state and maintains README.md, AGENTS.md, STATE.md, HANDOFF.md, DECISIONS.md, and LAUNCHER.md.

Project operational memory remains here. ai-operating-system supplies reusable global guidance only. Claude, Codex, ChatGPT, Hermes, and future tools are interchangeable launchers with non-authoritative local memory.

## Consequences

- Existing useful code and history are preserved during architecture reconciliation.
- Sensitive traveler, identity, booking, payment, and access data are excluded.
- The canonical implementation requires an explicit project decision.
- Documentation work does not authorize production changes.
