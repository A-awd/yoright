# Launcher Protocol

Claude, Codex, ChatGPT, Hermes, and future agents are interchangeable launchers. GitHub is the permanent source of truth.

## Launch

1. Open yoright.
2. Inspect the latest GitHub branch and commit state.
3. Read AGENTS.md, STATE.md, HANDOFF.md, relevant DECISIONS.md entries, and README.md.
4. Load only files necessary for the authorized task.
5. Apply ai-operating-system global rules without moving yoright memory there.

## Synchronize

After meaningful work, update STATE.md and HANDOFF.md, record decisions when necessary, and commit and push when authorized. If clones, hosted-platform state, or AI memory conflict, preserve evidence and use the latest approved GitHub state until a later decision replaces it.
